# Flynn의 분류법 (Flynn's Taxonomy)

1966년 Michael Flynn이 제안한 병렬 컴퓨터 구조 분류 체계.  
명령 스트림(Instruction Stream)과 데이터 스트림(Data Stream)의 수로 구분한다.

<br>

## SISD — 단일 명령 단일 데이터 (Single Instruction, Single Data)

```
명령 스트림: → [I]
데이터 스트림: → [D]
                  ↓
               처리 결과
```

- 전통적인 폰 노이만 구조의 직렬(serial) 컴퓨터
- 한 번에 하나의 명령, 하나의 데이터를 순차 처리
- **예시**: 과거 단일 코어 CPU, 순차 실행 프로그램

<br>

## MISD — 다중 명령 단일 데이터 (Multiple Instruction, Single Data)

```
명령1 → [P1] ↘
명령2 → [P2] → 동일한 데이터 D
명령3 → [P3] ↗
```

- 같은 데이터에 여러 명령을 동시에 적용
- 실제 구현 사례가 드문 이론적 분류
- **예시**: 우주왕복선 비행 컴퓨터 — 동일 입력을 5개 프로세서가 독립 계산 후 다수결로 결정, 내결함성(fault-tolerant) 시스템

<br>

## SIMD — 단일 명령 다중 데이터 (Single Instruction, Multiple Data)

```
명령 I → [P1, P2, P3, P4, ...]
           ↓    ↓    ↓    ↓
          D1   D2   D3   D4
```

- 동일한 명령을 여러 데이터에 동시에 적용
- **예시**: GPU, Intel SSE/AVX 벡터 명령어
- 딥러닝의 행렬 연산을 GPU가 가속하는 핵심 원리가 이 구조

<br>

## MIMD — 다중 명령 다중 데이터 (Multiple Instruction, Multiple Data)

```
명령A → [P1] → 데이터 DA
명령B → [P2] → 데이터 DB
명령C → [P3] → 데이터 DC
```

- 각 프로세서가 서로 다른 명령으로 서로 다른 데이터를 독립 처리
- 가장 일반적이고 유연한 병렬 구조
- **예시**: 멀티코어 CPU, 분산 시스템, 마이크로서비스

<br>

## 요약 비교

| 분류 | 명령 수 | 데이터 수 | 실용성 | 대표 사례 |
|------|---------|----------|--------|----------|
| SISD | 1 | 1 | 전통적 | 단일코어 CPU |
| MISD | N | 1 | 희귀 | 내결함성 시스템 |
| SIMD | 1 | N | 매우 높음 | GPU, 벡터 연산 |
| MIMD | N | N | 가장 높음 | 멀티코어, 분산 |

<br>

## AI 에이전트 오케스트레이션에 적용

Flynn 분류의 추상화 수준을 올리면 AI 에이전트 설계 패턴과 매핑된다.  
"명령" = 에이전트 역할/프롬프트, "데이터" = 처리 대상 컨텍스트로 재해석한다.

| Flynn | AI 플로우 패턴 | 예시 |
|-------|--------------|------|
| **SISD** | 단일 에이전트 순차 처리 | 에이전트 1개가 순서대로 작업 수행 |
| **MISD** | 동일 결과물에 다각도 독립 검증 | 같은 코드에 보안/성능/버그 리뷰 에이전트를 동시 적용 |
| **SIMD** | 동일 프롬프트를 N개 데이터에 병렬 적용 | `pipeline(files, f => agent("리뷰해줘: " + f))` |
| **MIMD** | 역할별 에이전트가 독립 태스크 처리 | staff-engineer + frontend-developer + security-reviewer 동시 실행 |

### MISD 패턴의 특별한 가치

하드웨어에서는 희귀하지만, AI 워크플로우에서는 강력한 패턴이다.

```
동일한 주장(데이터) D에 대해:
  검증자1 (회의론적 관점) → 반박 시도
  검증자2 (다른 각도)     → 반박 시도
  검증자3 (또 다른 각도)  → 반박 시도
  → 2/3 이상 반박 시 주장 기각
```

우주왕복선의 다수결 컴퓨터와 구조적으로 동일하다.  
신뢰도가 중요한 AI 출력(사실 검증, 코드 리뷰, 의사결정)에 적용할 수 있는 핵심 패턴이다.

<br>

## 연관 주제

- [Amdahl의 법칙](./AmdahlsLaw.md) — 병렬화의 이론적 한계, 직렬 구간이 전체 속도를 결정
- Gustafson의 법칙 — Amdahl 반론, 문제 크기를 키우면 병렬 효과 증대
- 캐시 일관성(Cache Coherency) — MIMD에서 공유 데이터 동기화 문제
- CUDA/OpenCL — GPU(SIMD) 프로그래밍 모델
- MapReduce — SIMD적 사고를 분산 환경에 적용한 패러다임
- Actor 모델 — MIMD적 비동기 메시지 패싱
