# 기술 면접 준비 전략
> 대상: 3년차 이상 서버 개발자 | 타겟: 성장 스타트업(Series B~D) | 준비 기간: 1~3개월

<br>

## 성장 스타트업이 3년차에게 기대하는 것

> **"이 사람이 당장 팀에서 오너십을 갖고 일할 수 있는가?"**

- 알고리즘 난이도는 빅테크보다 낮음 (Medium 수준으로 충분)
- **시스템 설계 비중이 높음** — 직접 설계하고 트레이드오프를 설명할 수 있는가
- 기술 결정의 이유를 논리적으로 설명할 수 있는가
- 주니어를 리드하거나 코드 리뷰를 할 수 있는 수준인가

<br>

## 우선순위 전략

4개 영역을 동등하게 준비하면 전부 얕아진다. **순서를 지킨다.**

```
[1순위] 시스템 설계     ← 3년차 변별력, 스타트업에서 가장 가중치 높음
[2순위] CS 기초         ← 시스템 설계의 기반, 모든 답변에 녹아듦
[3순위] 알고리즘        ← 스타트업은 Medium 이하, 꾸준함이 핵심
[4순위] 경험 기반       ← 매일 15분씩, 별도 시간 투자 최소화
```

**시간 배분 (하루 기준)**
| 영역 | 비율 | 하루 2시간 기준 |
|------|------|----------------|
| 시스템 설계 | 40% | 48분 |
| CS 기초 | 25% | 30분 |
| 알고리즘 | 25% | 30분 |
| 경험 기반 | 10% | 12분 |

<br>

## 3단계 준비 플랜

### Phase 1 — 기초 다지기 (1~3주)
CS 기초를 빠르게 훑으면서 알고리즘 감각을 되살린다.

| 영역 | 목표 |
|------|------|
| CS 기초 | OS / 네트워크 / DB 핵심 개념 1회독 |
| 알고리즘 | Easy~Medium, 하루 1~2문제, 패턴 익히기 |
| 시스템 설계 | 핵심 컴포넌트(캐시, DB, MQ) 개념 파악 |
| 경험 기반 | 이전 프로젝트 목록 작성 |

### Phase 2 — 핵심 역량 (4~7주)
시스템 설계를 메인으로 올리고 CS를 심화한다.

| 영역 | 목표 |
|------|------|
| 시스템 설계 | 주요 패턴 적용, 설계 문제 5개 이상 실습 |
| CS 기초 | DB 심화(락, 복제, 샤딩), 동시성 |
| 알고리즘 | Medium 안정화, DP/그래프 패턴 |
| 경험 기반 | STAR 구조로 핵심 경험 3~5개 정제 |

### Phase 3 — 통합 + 실전 (8주~)
말로 설명하는 연습, 약점 보강.

| 영역 | 목표 |
|------|------|
| 시스템 설계 | 45분 모의 면접 주 1~2회 |
| 알고리즘 | 시간 제한 두고 풀기, 코드 리뷰 연습 |
| 경험 기반 | 질문-답변 반복 연습, 피드백 반영 |

<br>

## 현재 공부 중인 것과의 연계

| 현재 공부 내용 | 면접 활용 포인트 |
|--------------|----------------|
| SOLID / DDD / OOP | "코드 설계 철학" 질문, 경험 기반 소재 |
| 의존성 관리 | "레거시 개선 경험", "리팩토링 결정 이유" |
| Just Enough Architecture (리스크 주도) | 시스템 설계 시 트레이드오프 프레임 |
| Flynn's Taxonomy | 분산/병렬 처리 설계 질문에서 깊이 추가 |
